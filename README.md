# 누띠 간식 계산기

반려견의 견종·체중·체형(BCS)·생활 패턴으로 하루 권장 칼로리와 **간식 허용량**을 계산하고, 고른 성분에 맞는 누띠 상품을 추천하는 정적 웹앱. 수제간식 쇼핑몰 [nutti.co.kr](https://nutti.co.kr) 의 유입 자산.

- 배포: [wjdtjddns98.github.io/Nutti-Calculator](https://wjdtjddns98.github.io/Nutti-Calculator/) (GitHub Pages)
- 스택: HTML · CSS · Vanilla JS, 빌드 과정 없음. 계산·추천 로직은 `js/calculator.js`, 상품·성분 데이터는 `js/products-data.js`
- 실행: `index.html` 을 브라우저로 열거나 `python -m http.server 8080`
